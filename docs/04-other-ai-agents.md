### ✅ Hermes Agent (NousResearch) — ALREADY SET UP

#### 🇬🇧 English

- **What it is:** A personal AI agent that lives in your terminal and Telegram — already configured for this community!
- **Why use it:** Free with NVIDIA NIM API, runs 24/7 on a free server, completely private
- **Model:** `NousResearch/Hermes-3-Llama-3.1-70B` — powerful, instruction-following LLM
- **How to set up:** See [`03-hermes-agent-setup.md`](./03-hermes-agent-setup.md)
- **Best for:** Individuals wanting a personal AI assistant accessible anytime via Telegram
- **GitHub:** https://github.com/NousResearch/hermes-agent

#### 🇵🇰 اردو

- **کیا ہے:** ایک ذاتی AI ایجنٹ جو آپ کے ٹرمینل اور ٹیلیگرام میں رہتا ہے — اس کمیونٹی کے لیے پہلے سے ترتیب دیا گیا!
- **کیوں استعمال کریں:** NVIDIA NIM API کے ساتھ مفت، 24/7 مفت سرور پر چلتا ہے، مکمل نجی
- **بہترین استعمال:** وہ افراد جو ٹیلیگرام کے ذریعے کسی بھی وقت ذاتی AI اسسٹنٹ چاہتے ہیں

#### 🗣️ Roman Urdu

- **Kya hai:** Ek zati AI agent jo aapke terminal aur Telegram mein rehta hai — is community ke liye pehle se tayyar!
- **Kyun istemal karein:** NVIDIA NIM API ke saath muft, 24/7 muft server par chalta hai, bilkul private
- **Behtareen:** Woh log jo Telegram ke zariye kisi bhi waqt personal AI assistant chahte hain

### 🤖 AutoGPT

#### 🇬🇧 English

- **What it is:** The pioneering "auto-agent" that runs tasks autonomously — searches web, writes files, executes code
- **Why use it:** Good for complex multi-step tasks, massive community and plugin ecosystem
- **Limitations:** Can go in loops, expensive with GPT-4 API, not ideal for Telegram
- **How to run:** Docker or local Python install
- **Cost:** Requires OpenAI API key (paid) or compatible free API (NVIDIA NIM works!)
- **GitHub:** https://github.com/Significant-Gravitas/AutoGPT
- **Best for:** Power users who want AI to do complex tasks autonomously

#### 🇵🇰 اردو

- **کیا ہے:** پہلا "آٹو-ایجنٹ" جو ٹاسک خودکار طریقے سے چلاتا ہے — ویب سرچ، فائلیں لکھنا، کوڈ چلانا
- **کیوں استعمال کریں:** پیچیدہ کثیر مرحلہ ٹاسک کے لیے بہترین، بڑی کمیونٹی
- **محدودیات:** لوپ میں پھنس سکتا ہے، GPT-4 کے ساتھ مہنگا
- **بہترین استعمال:** طاقتور صارفین جو AI سے پیچیدہ کام خودکار کروانا چاہتے ہیں

#### 🗣️ Roman Urdu

- **Kya hai:** Pehla "auto-agent" jo tasks khud-ba-khud chalaata hai — web search, files likhna, code execute karna
- **Kyun istemal karein:** Pechida multi-step tasks ke liye acha, bari community
- **Mahdoodiyat:** Loop mein phas sakta hai, GPT-4 ke saath mehnga
- **Behtareen:** Power users jo AI se pechida kaam automatic karwana chahte hain

### 👥 CrewAI

#### 🇬🇧 English

- **What it is:** A framework for building teams of AI agents — each with a specific role
- **Why use it:** Agents can have roles like Researcher, Writer, Analyst and work together in sequence
- **Example workflow:**
  ```
  Research Agent → finds information
       ↓
  Writer Agent → writes the article
       ↓
  Editor Agent → reviews and polishes
  ```
- **How to run:** `pip install crewai` + Python script
- **GitHub:** https://github.com/crewAIInc/crewAI
- **Best for:** Developers building multi-agent, role-based workflows

#### 🇵🇰 اردو

- **کیا ہے:** AI ایجنٹس کی ٹیمیں بنانے کا فریم ورک — ہر ایجنٹ کا مخصوص کردار
- **کیوں استعمال کریں:** ایجنٹس کے کردار ہو سکتے ہیں جیسے محقق، لکھاری، تجزیہ کار
- **مثال:** ریسرچ ایجنٹ معلومات ڈھونڈتا ہے → رائٹر ایجنٹ مضمون لکھتا ہے
- **بہترین استعمال:** ڈویلپرز جو ملٹی ایجنٹ، کردار پر مبنی ورک فلو بنا رہے ہیں

#### 🗣️ Roman Urdu

- **Kya hai:** AI agents ki teams banane ka framework — har agent ka khaas kirdar
- **Kyun istemal karein:** Agents ke kirdar ho sakte hain jaise researcher, writer, analyst
- **Misaal:** Research agent maloomat dhundta hai → Writer agent mazmoon likhta hai
- **Behtareen:** Developers jo multi-agent, role-based workflows bana rahe hain

#### 🗣️ Roman Urdu

- **Salahiyatein:** Code likhna, test chalana, web browse karna, bugs theek karna
- **Zarooriyat:** Docker, 8+ GB RAM

### 🧑‍💻 Aider

#### 🇬🇧 English

- **What it is:** An AI pair programmer that works right inside your terminal
- **How to use:** Run `aider` in your code directory → ask it to add/fix/change code in plain English
- **Why use it:** Extremely practical, works with any existing codebase, supports many LLMs (including free ones!)
- **GitHub:** https://github.com/paul-gauthier/aider
- **Best for:** Developers who want hands-on AI assistance with real coding day-to-day

#### 🇵🇰 اردو

- **کیا ہے:** AI جوڑی پروگرامر جو آپ کے ٹرمینل میں کام کرتا ہے

- **بہترین استعمال:** ڈویلپرز جو روزانہ کوڈنگ میں AI مدد چاہتے ہیں

- **Kaise istemal karein:** Apne code folder mein `aider` chalao → seedhi baat mein code badalne ko kaho
